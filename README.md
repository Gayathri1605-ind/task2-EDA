# Task 2 - Exploratory Data Analysis (EDA) & Business Intelligence

## Objective
The objective of this task is to analyze the cleaned Superstore dataset and uncover meaningful business insights using Exploratory Data Analysis (EDA), SQL queries, and data visualization techniques.

# Dataset Used
Cleaned Superstore Dataset

# Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite
- Google Colab

# Tasks Performed

## 1. Data Exploration
- Loaded cleaned dataset
- Checked dataset structure
- Analyzed data types
- Verified missing values
- Checked duplicate records

## 2. Descriptive Statistics
- Calculated summary statistics
- Identified maximum and minimum values
- Analyzed average sales and profit

## 3. Univariate Analysis
- Sales distribution
- Category-wise sales analysis
- Profit analysis

## 4. Multivariate Analysis
- Sales vs Profit relationship
- Correlation heatmap
- Monthly sales trends

## 5. SQL Business Analysis
- Top products analysis
- Region-wise sales
- Category-wise profit
- Customer profitability analysis

## 6. Dashboard Mock-up
Created static dashboard containing:
- Total Sales
- Total Profit
- Total Orders
- Best Region
- Top Product
- Sales Trend
- Profit Analysis

# Key Business Insights

## Insight 1
Technology category generated the highest sales among all categories.

## Insight 2
Sales and profit show a positive relationship, indicating higher sales generally lead to higher profit.

## Insight 3
Some products generated high sales but low profit, suggesting discount or pricing issues.

## Insight 4
Monthly sales analysis showed seasonal sales trends during certain months.

## Insight 5
Certain regions contributed significantly more revenue compared to others.

## Insight 6
Discounts negatively impacted profit margins in several orders.
